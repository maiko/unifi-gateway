# Enterprise gateway coverage

This tracker covers the controls exposed by Gateway Enterprise (`UXGENT`) in
unmodified UniFi OS Server and Network that have a stock VyOS equivalent. A
full release requires a clean enrollment, native UI control, observed packet
or service behavior, accurate status, and recovery after withdrawal, failure and
reboot. Shadow Mode requires two independent routers.

| Evidence | Tested scope |
| --- | --- |
| [Enterprise UI and forwarding](verification.md#enterprise-directed-adoption-and-firewall) | Directed adoption, authenticated reconnect and an IPv4 firewall create, edit and delete on prepared VLANs |
| [Stock router qualification](verification.md) | Includes paired VyOS HA, routing, inspection and recovery. Each result identifies its control path. |
| [Historical UXG Pro reference](uxg-pro-qualification.md) | Earlier UI, packet and protocol evidence for shared code. Enterprise qualification is tracked here. |

The recorded controller is UniFi OS Server 6.0.21 RC with Network
11.0.104-37279-1. The stock router image is VyOS 2026.11.22-0018-rolling.
The greenfield package, service layout and names require fresh release
qualification. [Operator guide](provisioning.md)

## Acceptance

Use the native UI on an enrolled Enterprise gateway. Record exact builds,
the controller revision, running and saved router state, an independent positive
test and an unrelated control. Edit and withdraw a change, exercise a rejection,
and verify the last known good revision, ownership and management access. For
telemetry, record loss of the source and recovery. For timed actions, inspect
progress while the action is running and its terminal state.

**Partial** means a narrower workflow has evidence. **Open** means the acceptance
check remains outstanding. **Reference check** means the Enterprise control or
its protocol still needs confirmation. **Retired** preserves the ID of a former
requirement. Rows referring to prior native workflows use their recorded model
and build until an Enterprise result is recorded.
